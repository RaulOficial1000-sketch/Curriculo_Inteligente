# Portfólio de Raul Teixeira Gomes da Silva

Portfólio e currículo interativos em HTML, CSS e JavaScript puros, sem dependências, publicados com GitHub Pages.

**Endereço do site:** https://rauloficial1000-sketch.github.io/

## O que tem

- Apresentação com efeito de digitação e modo claro/escuro (salvo no navegador)
- Sobre mim, habilidades, projetos e contato
- Galeria interativa de certificados, com busca, filtros, zoom e visualização frente/verso
- Responsivo (celular, tablet e computador)

## Estrutura

```text
├── index.html           página principal
├── certificados.html    galeria de certificados
├── certificados/        imagens dos certificados (com marca d'água, RG coberto)
├── curriculo.pdf        currículo para download
├── robots.txt
└── README.md
```

## Como atualizar

- **Novo projeto:** em `index.html`, procure `PARA ADICIONAR UM NOVO PROJETO` e copie o bloco indicado.
- **Novo certificado:** em `certificados.html`, procure `PARA ADICIONAR UM NOVO CERTIFICADO`, copie o bloco e coloque as imagens em `certificados/`.
- **Novo currículo:** troque o arquivo `curriculo.pdf` mantendo exatamente esse nome.

## Privacidade

Tudo que fica neste repositório é público. Por isso:

- Os certificados são publicados só como imagens com marca d'água e documentos pessoais cobertos.
- Nunca envie PDFs originais de certificados nem senhas.
